## 📌 Overview
An interactive 2D desktop game focusing on object-oriented programming logic, canvas rendering, state management, and real-time audio integration.

## 🚀 Key Features
- **Interactive Gameplay**: Smooth player controls and physics-based collision handling.
- **Dynamic Audio Integration**: Integrated audio feedback for player actions (e.g., scoring, falling, and stage completion).
- **Asset Management**: Custom visual sprites, animated background elements, and state-driven game logic.

## 🛠️ Built With
- **Language**: JavaScript (ES6)
- **Framework / Library**: p5.js (Canvas Rendering & Sound Engine)
- **Markup / Styling**: HTML5, CSS3
